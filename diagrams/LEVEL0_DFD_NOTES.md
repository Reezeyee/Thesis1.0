## What was wrong in the original draft, and what changed

| Original draft | Actual system | Fix |
|---|---|---|
| "Farm Owner/Admin" box **and** a separate "Admin" box | Admin and Owner are different roles (`ADMINISTRATOR`, `OWNER`); Owner is read-only (profit/revenue only) | Split into **Administrator** and **Farm Owner (read-only)**; removed the duplicate Admin box |
| No Buyer entity | Buyers register, set a location, browse listings and place pickup orders (`buyer_orders`) | Added **Buyer** entity |
| 5.0 Buyers' Map received "Buyer information" from the farm worker | Buyer location comes from the buyer's own profile; Admin views the map (Nearby Buyers) | Buyer → 5.0, 5.0 → Admin |
| 7.0 Maintenance = "Employee, buyer records" | Web Maintenance page = **Buyer Records** + **Buyer Orders** | Renamed 7.0 "Maintenance (Buyer Records & Orders)", D7 = Buyer Orders |
| Repair jobs not shown | Admin assigns equipment/sprinkler repair jobs to Maintenance workers (`repair_jobs`) | Shown under 4.0 Inventory & Equipment |
| Worker flows to 3.0 were admin-only data (layout, irrigation setup) | Workers submit harvest readiness, pest/disease and irrigation damage reports; Admin sets sections, trees, schedules | Flows split per role |
| Classification had no external service | Ripeness uses the Roboflow hosted model; bean/species uses the on-device TFLite model | Added **Roboflow Detection API** external entity on 2.0 |
| SMS Center / Owner Messages missing | Both exist (`sms_messages`, `owner_admin_messages`) | Added **8.0 Communication**, D8 Messages |
| Attendance/leave missing | Workers clock in/out on mobile; Admin reviews in Users Management | Added to 1.0 |
| "Admin → Data and Sync: view reports, manage users" | Sync = offline local cache on device, uploaded to Firestore when online; Admin sees DB health (Telemetry Monitor) | 9.0 Data and Sync with worker offline records, D9 Local Data |
